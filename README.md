# لیست کارها (Todo List) با جاوااسکریپت و LocalStorage
 
یه اپلیکیشن ساده‌ی لیست کارها که با HTML، CSS و JavaScript خالص (بدون فریمورک) ساخته شده. قابلیت‌های کامل CRUD رو داره و داده‌ها با LocalStorage توی مرورگر ذخیره می‌مونن.
 
## امکانات
 
- اضافه کردن تسک جدید
- تیک زدن تسک‌های انجام‌شده (چک‌باکس + خط خوردن متن)
- ویرایش تسک‌های موجود
- حذف تسک‌ها
- ماندگاری داده‌ها بعد از رفرش صفحه (LocalStorage)
- رابط کاربری با تم تیره

## تکنولوژی‌ها
 
- HTML5
- CSS3
- JavaScript 
- Font Awesome (برای آیکون‌ها)
